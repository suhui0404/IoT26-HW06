# IoT26 TeamJ HW06 - Raspberry Pi YOLO Object Detection

## 1. Objective

- Installing YOLO on Raspberry Pi and recognizing cars or car license plates displayed on a computer monitor.

## 2. Environment

- Raspberry Pi 5
- Raspberry Pi OS (64-bit)
- Python 3
- YOLO
- Camera Module

## 3. Circuit

### Components
- Raspberry Pi
- Raspberry Pi Camera Module
- Breadboard

## 4. Files

- Python source code is included in the repository.
- Result images and GIF files are included in the result folder.

## 5. Issues / Troubleshooting

### 1. Camera Module Issue

Cause
- The camera module being used did not operate properly.

Solution
- Replaced the camera module with a different one and reconnected it to solve the problem.

## 6. Conclusion

Through this project, I learned how to install YOLO on Raspberry Pi and use a camera module to recognize cars and car license plates. This project provided experience in combining camera sensors and image processing technology within an IoT environment using Raspberry Pi.

In particular, I was able to observe how input data from the camera could be analyzed to detect specific objects in real time. This helped me understand how sensor data and image information can be utilized in IoT systems.

During the project, a camera module issue occurred. Initially, I suspected problems with the code or Raspberry Pi connection, but after replacing the camera module with another one, the system operated normally. This experience highlighted the importance of checking hardware components as well as software when troubleshooting IoT systems.

As a result, this project helped me understand how camera sensors and object recognition technology can be integrated in Raspberry Pi-based IoT environments and how image data can be applied to various IoT systems.
